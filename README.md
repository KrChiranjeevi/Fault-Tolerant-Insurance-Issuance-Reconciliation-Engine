# PolicyFlow

PolicyFlow is an enterprise policy lifecycle management and workflow automation platform designed to streamline policy authoring, review cycles, approval routing, compliance auditing, and distribution.

## 🚀 Tech Stack

- **Frontend**: [React](https://react.dev/) (with Vite & TypeScript) — Modern, component-driven responsive user interface.
- **Backend**: [Laravel](https://laravel.com/) (PHP 8.2+) — Robust RESTful API architecture, authorization gates, and workflow queue processing.
- **Database**: [MySQL 8.0+](https://www.mysql.com/) — Relational data storage for policies, revision histories, audit logs, and access control.
